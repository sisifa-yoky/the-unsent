## ① 課題名

the unsent（言えなかったメール。）

## ② 課題内容

the unsentは、誰かに伝えたかったけれど、送ることのなかった言葉を保存しておくサイトです。



宛先や件名、カテゴリー、本文を入力してメールを作成し、ブラウザ上に保存することができます。



保存したメールは一覧からいつでも読み返すことができ、必要に応じて削除することもできます。



実際にメールを送信するのではなく、伝えられなかった言葉を自分のために残しておくことをコンセプトにしています。

## ⑤ 工夫した点・こだわった点

今回、特にこだわったのは、カテゴリーごとに異なる色やアイコンを設定し、メールの内容に合わせて見た目が変わるようにしたことです。



例えば、「さよなら」「ありがとう」「ごめんなさい」など、カテゴリーごとに色とアイコンを設定し、保存したメールの一覧や詳細画面にも反映されるようにしました。



また、LocalStorageを使って、作成したメールをブラウザ上に保存する仕組みを実装しました。
```javascript
function saveMessage(message) {
    localStorage.setItem("message_" + message.id, JSON.stringify(message));
}
```

`JSON.stringify()` を使ってメールの情報を文字列に変換し、LocalStorageに保存しています。



さらに、`Date.now()` を使ってメールごとにIDを設定することで、それぞれのメールを個別に管理できるようにしました。



保存したメールは一覧に表示され、クリックすると詳細を読み返すことができます。

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

一番難しかったのは、LocalStorageを使ったデータの保存と読み込みでした。



宛先や件名、カテゴリー、本文など、複数の情報を一つのデータとして管理し、保存した内容を正しく読み込んで一覧や詳細画面に表示する必要がありました。



また、メールをクリックしたときに、そのメールの情報だけを取得して詳細画面に表示する部分や、削除したときに一覧の表示も更新する部分にも苦労しました。
